# v1802 — The glaze shelf (MOCKUP, revised after critique)

Status: MOCKUP. Data is the synthetic `fixture.json`, never a real reading. Everything in concept brief v2 and v3 applies.

## Critique fixes
1. **Safe test no longer fabricates a pass (§2).** The test verifies only what Worlds can verify without the provider: the credential reference is well-formed, and the owning Memory app answers a local handshake. The pass reads "Local check passed — the provider was not contacted." `sync.provider-reachable` stays `unavailable` with the fixture's "provider timed out", and the published Notes Sync pot carries the fixture state verbatim (`unavailable`, "Unavailable").
2. **The live feed can tick, and its write set is defined (§6a).** The store owns its clock, re-based at load. One tick is one store update that all three views render from. "Moves to stale" is a defined freshness-window crossing, not a rewrite of Media Shelf's `healthy` state. `#live-toggle` pauses the store clock.
3. **Unknown and Stale come from the fixture (§6).** `garden-camera` (Unknown, with its `unknownReason`) and `nightly-backup` (Stale, with its `summary`) are connectable services on the shelf and in Agent facts. "App didn't load" is a separate embed state with its own copy. One drop-off is scripted.
4. **Whimsy is lifted out of the structure (§1, §6b, §11).** Every pot starts with the same fixed text state row. The face is a small echo of the state word and never its only carrier. The per-service glaze is dropped. §11 now says how this differs structurally from hall-of-doors and key-ring.
5. **OpenDesign picks now land (§8).** The skill picks with nowhere to land are dropped. The mechanics that do land are named with their targets, and ds-clay's type is mapped to a named offline stack with a pinned scale.

## 1. Metaphor in one line, and the main gesture.
Worlds is a studio shelf. Each connected service sits in its own pot, which is a container idiom only. A pot is a plain text row of state first, a name, and a paper **tag** naming the owner. The main gesture is **lift a pot's lid**: select a service and its owning app opens in a frame beside (desktop) or over (mobile) the shelf, with its tag directly under it. A visible MOCKUP label stays in the rail (desktop) and the top bar (mobile) throughout.

## 2. Integration model: how a service plugs in, where it lives in the shell, how its facts flow.
**Start state:** `media-shelf` (Media Shelf, `healthy`) and `front-door` (Front Door, `needs_attention`, "Needs a human"). Front Door is selected.

**`#add-service`** (header on both layouts) opens Connect. **Discover** lists every unconnected fixture service with its fixture state, name and owner:
- Notes Sync, `unavailable`. This is the scripted path.
- Nightly Backup, `stale`, with its summary.
- Garden Camera, `unknown`, with its `unknownReason`.
- Studio Printer, `unavailable`, with its summary.
- Local Weather, `not_configured`. Its row shows `emptyReason`, and its only action is the "Open provider settings" hand-off. It has no facts to publish.

Any listed service can be connected through the same flow, and each is published with its fixture state verbatim.

**Six real `<button>` steps:**
1. **Discover.**
2. **Credential reference.** It takes a reference name only. A pasted secret (long token-like text, or text that does not start with `ref:`) is refused with "Worlds keeps a reference to the credential, never the secret". Validation runs on blur, and the input is kept on error.
3. **Safe test.** It runs two local checks:
   - (a) the reference is well-formed;
   - (b) the owning app answers a local handshake. The handshake is a mock, labelled as one.
   
   States are idle, running, passed and failed. The failure paths are real and driven by input:
   - a malformed reference fails (a) with its cause and "Fix the reference, then test again", input preserved;
   - the Settings demo switch "Pretend the Memory app didn't answer" fails (b) once, with "Try the test again".
   
   The pass says "Local check passed — the provider was not contacted." Under it is a fixed line: "Provider reachability: not tested. Last result: provider timed out (2 attempts)." The second line is fixture text. No provider is called, and nothing here is described as a provider reading.
4. **Preview.** Each fact appears with its fixture state word. For Notes Sync:
   - `sync.provider-reachable`: Unavailable, source external.
   - `sync.local-pending`: 3 notes, Live.
   - `sync.last-synced`: Stale.
5. **Choose what to publish.** One checkbox per fact id, plus a plain sentence on what is shared. Facts whose agent permission is `none` stay listed, with their named reason.
6. **Publish.** The new pot settles onto the shelf with a lid animation and the line "Notes Sync is on the shelf — Unavailable. Local notes still work."
   - The pot carries the fixture state `unavailable`, label "Unavailable".
   - Its freshness is `stale`, source `none`.
   - It has the three fact rows above, and the unpublished facts are absent.
   - Its recovery action is "Check provider now", which hands off to the owning Memory app (`app://memory`) and runs nothing in Worlds.

**One store.** One in-memory store keyed by fact id (plus a service record per service) feeds three views: Home (shelf and attention count), the service dock (app frame plus its tag), and Agent facts. A change is one `setState`, then one render pass of all three views from the same snapshot and the same clock value.

**`#simulate-change`** applies `lock-back-door` to `frontdoor.back-door`, per `crossViewExample`:
- Front Door becomes `healthy`, and the fact reads `locked`.
- `attentionCount` becomes 0, and the Home count says "Nothing needs you".
- The tile resizes to match its new need, with no size jump under reduced motion.
- All three views change in the same update, optimistically at once, then show a "settled" mark about a second later.
- The label reads "Mock owner report — Worlds locks nothing. Locking happens in Project Home." Before the change, the fact's action is a hand-off to Project Home.

**`#disconnect`** sits in the dock header of the selected service and on the mobile selected strip. It opens an inline confirmation naming the service, with a button labelled "Disconnect" and a Keep button. Afterwards:
- the pot is gone and the dock selects the next-needed pot (or the empty state);
- a line says what is gone: "Media Shelf's facts and app frame are no longer here; Media still has its data";
- Home, Agent facts and the rest keep working. Historical retention is UNKNOWN.

## 3. Navigation between Worlds and a service (phone and desktop).

- **Memory** shows what Worlds keeps from published facts: fact id, label, last published value and state. Its contents beyond fixture facts are UNKNOWN and said so.
- **Settings** holds:

- **Keyboard:** all destinations and pots are reachable by Tab, with Enter/Space to open. Arrow keys move between pots, Esc closes the sheet or confirmation, and the focus ring is always visible.

Every state shows a word and a face shape, never colour alone.

- **Stale:** Nightly Backup, "Stale", with its summary, last success 2026-10-09T06:00:00Z and age words. Its facts stay stale, with no invented refresh.
- **Unknown:** Garden Camera, "Unknown", with its `unknownReason` and its fact values shown as "Unknown", never blank.

### 6a. The live feed (exact behaviour)
- **Clock.** The store owns a clock. At load it re-bases synthetic timestamps: `offset = Date.now() - Date.parse(generatedAt)`, which keeps each fixture `ageSeconds` true (Media Shelf reads about "28s ago", Nightly Backup about "8h ago"). This is labelled in Settings and Memory as a "demo re-base of synthetic data". `store.now = Date.now() - offset` advances while Live is on.
- **Age words.** Every age word everywhere is `now - checkedAt` (or `observedAt`), computed at render from `store.now`. No view keeps its own timer.
- **Tick write set (every 4 s, one `setState`).** For each connected service whose freshness source is `local` and whose fact is `live`, write `observedAt = now` and the service `freshness.checkedAt = now`. Values never change on a tick. Facts that are `stale`, `unavailable` or `unknown` are never refreshed by the feed, so Worlds invents no readings. Home tile, dock tag and Agent-facts freshness cells all re-render from that one update, and each row exposes `data-fact-id` and `data-freshness` so this is checkable.
- **Freshness window.** A live fact whose age exceeds 60 s without a new observation reads "Stale". The service `state` is never rewritten by the feed, only freshness. Only `#simulate-change` changes a service state.
- **Missed check (the one scripted drop-off).** About 30 s after load, then every ~90 s, the demo feed skips one check for Media Shelf and labels it "Demo feed: Media missed a check". Its facts age past the window and read Stale, and the tile shows a "Check now" hand-off (Open Media app). On the next tick after 25 s, the feed writes a fresh observation and it recovers ("Back to live"), with a calm settle. The service state word stays "Healthy" throughout, and only the freshness word changes.
- **Pause.** `#live-toggle` ("Live: on/paused") is in the header, on by default. Paused means the store clock stops. Ages freeze, no tick fires, the label says "Paused — readings frozen at HH:MM:SS", and the freeze is visible in the data. On resume the clock continues from the frozen instant, so there is no sudden staleness jump. Reduced motion changes animation only, never the data feed.

### 6b. Whimsy, in the details (not in the structure)
- **Uniform state row.** Every pot's first element is a text state row, identical in position and type on every tile: **state word · reason · freshness · "Agent sees / Human acts"** (for example "Agent sees 3 of 3 · You can act on 1"). The shelf scans like a list of states drawn inside pots. The swatch band is the row's background only, and the word always carries the state.
- **The face** is a 24px inline SVG at a fixed corner of the state row, an echo of the state word. It blinks, and each state has a distinct shape. Removing it loses nothing.
- **Other details.** "Connected" is a lid that settles on the new pot. Copy is kind and specific: "Front Door is waiting on you. Nothing else is." Ticks change "checked 2s ago" quietly. Reduced motion removes the blink, lid and tilt but keeps all data updates.

## 7. Borrowed from Homarr / Dashy / HA cards / MCP ext-apps, and what is deliberately different.
- **Homarr:** one integration drives the shelf, the dock and the agent view.
- **Dashy:** apps open in place.
- **HA cards:** literal state words and a shared subscription (one store, one render).
- **MCP ext-apps:** contained UI with host-owned permissions.
- **Different:** the shell owns the tag, so a service cannot restyle its own status. This is not a dashboard of charts, only owned things with honest state.

## 11. How it differs from C, and what it keeps.
**Keeps:**
- the persistent shell (Home, Connect, Memory, Settings);
- owner-labelled services;
- the owning app docked beside its shared fact card;
- six-step Connect for Notes Sync with the same preview ids;
- fixture wording and fallback links verbatim;
- one fact store;
- honest named-disabled permissions;
- the same checker ids.

**Differs from C:**
- C is a flat, fixed-order register of bays with a static bezel and a no-motion signature. This is a gapless shelf whose tile size follows need (the needs-you tile first and largest), with a swing-and-settle on state change.
- C's fact card is a panel. Here it is a reusable tag that is the same object on Home, in the dock and in Agent facts.
- C's palette is white with a restrained orange edge. This one is cream, oat and named swatches.
- C's mobile is a one-column list with Back. This has a bottom tab bar and a bottom sheet.
- C used no live feed. This one ticks every 4 s from a store clock.

**Differs structurally from the anti-repeat entries "hall of doors" and "key ring".** Those file owners in fixed bays or slots, so position is identity. This docks the owner's app beside the fact tag, lets tile size follow need so position follows urgency, and uses the pot only as a container for a plain state row.

It borrows C's honesty and structure, not its look.
